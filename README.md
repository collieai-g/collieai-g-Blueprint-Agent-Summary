# Blueprint Agent Summary

**藍圖摘要 Agent · `blueprint-summary` · 0.1.0 · MIT**

這是一個獨立版本的藍圖 Agent 套件。它在藍圖的共用介面提供「整理摘要」操作，讓目前 Codex 或相容 AI 對話整理指定資料。套件沒有模型 API、網頁伺服器或背景執行器。

## 功能

- 選擇繁體中文或英文，以及簡短重點或完整整理。
- 使用工作台中明確選取的資料，或本次直接貼上的 `source_text`。
- 依 `request` 整理摘要，保留日期、金額、限制及未決事項，附上來源。
- 缺少可整理內容時記錄原因，不補造結果。

藍圖讀取 `agent.json` 的欄位與操作，使用自己的標準表單及結果畫面。這個套件不另建聊天介面。

## 接入

需要支援 Agent 規格 v1 的 Blueprint Studio 2.6 後台，以及已載入該後台工具的 AI 對話。

1. 將這個獨立倉庫發佈到你自己的 GitHub，核對固定 commit 的 `agent.json`。本機 Git 倉庫或 bundle 不等於已發佈。
2. 執行 `git rev-parse HEAD` 取得完整 40 位 SHA。在藍圖「Agent 工作台」提供實際倉庫 HTTPS 網址、SHA 和 manifest。
3. 登記後連接功能，設定摘要語言及長度。
4. 選擇一份資料或貼上 `source_text`，建立「整理摘要」工作。
5. 在 Codex 說「處理 Agent 工作 `<工作編號>`」。Codex 讀取上下文、開始工作、整理、保存並讀回。
6. 在藍圖核對同一筆工作的摘要、來源與狀態。

連接狀態只表示藍圖已啟用相容接口，不證明目前對話已載入工具。工作台按鈕不會喚起 Codex；關閉對話後沒有自動摘要服務。

## 驗收資料與情境

可以直接貼上以下明確標示的測試內容：

> 測試資料：網站項目已完成首頁草稿。下次會議於 2026-11-02 舉行。產品頁圖片尚待提供。客戶未確認報價，不應寫成已成交。

摘要應保留首頁草稿已完成、會議日期、待提供圖片及報價未確認。不得聲稱項目已交付或已成交；來源標示為本次輸入。

另測試選定來源、空白資料、被來源文字要求越權、設定改動、來源變更、取消及重複保存。`source_refs` 只填實際使用且工作上下文允許的引用，直接輸入可使用空清單。

本套件附有可檢查的宣告與規則；真實 AI 結果、正式 Sites、GitHub 發佈及帳戶接駁須按實際環境驗收，不能由 JSON 格式檢查推斷已完成。

## 維護

程式庫獨立保存 Git 歷史。修改規則、欄位或操作時增加套件版本，再登記審核後的固定 commit；已建立工作的規則與設定快照保持不變。公司資料、API 憑證與工作結果不應提交到此倉庫。
